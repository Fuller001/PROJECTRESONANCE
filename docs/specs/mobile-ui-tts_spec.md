# 手机界面与 TTS 优化

用户要求先优化手机 UI，并测试 TTS；完整 NPU 实验暂停，保留数据和隔离资源以便继续。正式应用保持现有 CPU 模型、录音、训练、短语、云端 TTS 与音色克隆路径。

## 手机布局

- 延续现有暖白 / 橙色视觉、深色和高对比模式。使用首页先呈现标题、识别方式和足够大的录音按钮。
- 音色选择从所有页面的顶部移到设置页；使用页保留一行当前音色和可点击的设置入口。
- 底部四项导航保持可见，各项点击区域至少 48px，内容有对应底部留白，兼容系统安全区与 320px 小屏。切换主要页面回到页首。
- 手机显示“点击开始 / 停止”，键盘提示仅在有精细指针和悬停能力的设备显示；保留键盘功能。
- 音色整行可选、试听按钮至少 48px，可停止请求和播放。模型管理和引擎标题在小屏换行，技术信息折叠到详情，下载/取消与状态始终可见。
- 搜索、短语添加表单和识别结果操作在窄屏不横向溢出。训练、词表功能及原有数据不变。

## TTS 正确性

- 普通朗读使用当前选中的音色；试听直接传入点中的音色，不能依赖异步 React 状态先完成。
- 云端请求使用当前语速，播放音量遵守设置（包括静音）。云端没有系统音色/音高能力，不展示这些无效控制，也不以 WebView 缺少系统语音包判断云端不可用。
- 加载、播放、停止与错误状态可见。停止/后台/卸载后不播放迟到响应。错误出现在设置试听处。
- 服务应返回音频；HTML 等非音频响应明确报告服务配置错误，不能作为音频播放成功。

## Step Plan 接入（用户补充要求）

- 默认朗读服务改为 Step Plan，保留原云端服务选项。固定 Base URL 为 `https://api.stepfun.com/step_plan/v1`，请求 `POST /audio/speech`，使用模型 `stepaudio-2.5-tts`；不把 Chat Completions 或 Anthropic Messages 地址用于合成。
- 按官方文档发送 `input`、StepAudio 音色 ID、`speed`、`response_format=mp3`、`volume=1`；实际播放音量仍在本机控制，包括 0 静音。单次文本最多 1000 字符，不自动重试消耗 Credit 的请求。
- Step Plan 和设置页可直接进入，不依赖原云端登录；原云端服务保留原鉴权。网络合成总时限 75 秒，停止/后台/销毁仍优先取消。密钥更新完成前暂时拒绝新朗读，提示稍后重试，保存成功后可立即试听。
- 应用设置中可输入、保存、替换、移除完整 API Key。密码输入框保存成功后清空，仅返回“已配置”状态，不回显密钥；拒绝带省略号、星号、空格的脱敏片段。没有完整 Key 时提示用户到设置填写。
- Android 用 Keystore AES-GCM 加密后保存至应用私有偏好，密钥直接由原生 HTTPS 请求使用，读取状态不把密钥返回 JavaScript。密钥不写入普通 AppSettings、导入导出、日志、源码或 APK。网页端只在内存中保存本次会话密钥，刷新后需要重新填写。
- HTTPS 请求固定发往用户指定的 StepFun endpoint，不自动跟随重定向或发送原 Worker Cookie。取消、后台或销毁会断开原生连接，前端继续使用代际标记丢弃迟到响应。只接受非空且有大小上限的 audio/* 响应，401/403/429/HTTP 错误均给出中文说明。
- Step Plan 与原服务分开保存音色选择；官方音色使用文档确认的 ID，自定义音色 ID 输入保留。密钥变更和服务切换会停止当前朗读。
- 交付需通过传输/鉴权/取消/非音频/密钥状态回归、TypeScript、lint、Vite 和 Android 检查，覆盖安装保持模型与用户数据。完整 Key 未提供时只验证未配置提示、界面及模拟契约，明确真实音频未验收，不使用用户消息中的脱敏片段请求。

官方依据：[语音合成](https://platform.stepfun.com/docs/zh/api-reference/audio/create-audio)、[官方音色](https://platform.stepfun.com/docs/zh/guides/developer/tts#官方音色清单)。

## 验收

类型检查、现有测试、针对音色/语速与播放状态的回归测试、ESLint 和生产构建通过。用 320/360/412px 移动视口检查首页、设置、训练及短语页，检查大字/高对比和底部导航。更新 Android debug APK 并覆盖安装，保留手机模型、receipt、auto 设置和用户数据；记录真实手机 TTS 成功或具体失败证据，不能把模拟播放视为真实服务成功。结束时恢复临时 stay-awake / ADB 转发。

仓库引用的 mandatory-workflow / quality-gates 文件缺失，独立审查 provider 不可用；使用手工设计与源码复核，记录该限制，不宣称独立批准。
