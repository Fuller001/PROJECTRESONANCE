## 制作方式

1. `capture-stills.py`：真机逐页导航，校验“底部导航选中态 + 页面正文对比度 + 连续两帧一致”后才截图，避免截到转场或发白帧。
2. `compose-mobile-journey.py`：把每张真机静帧做 5% 缓慢推拉与位移，套入圆角手机卡片，加品牌页眉、章节标签、字幕、进度条，`xfade` 交叉淡化合成。
3. 交付前校验：时长、分辨率、帧率、无黑帧段、SHA-256。

重新生成：

```powershell
python deliverables/evidence/demo/capture-stills.py
python deliverables/evidence/demo/compose-mobile-journey.py
```

## 表述边界

- 影片按产品口径使用“端侧大模型推理”，不出现芯片型号、机型或“APK 内置模型”等实现细节。
- 画面全部来自真机安装版页面；影片不做合成 UI 替换。
- 片尾注明：官方 6.74 秒样音端侧识别 3.3–3.8 秒（单独实测），朗读需网络与用户自己的 Key。
- 模型实际参数量约 1.7B（GGUF 元数据 `model params = 1.72 B`）；如需对外写“3B”，需先统一模型口径，避免与技术材料冲突。
